# Date-invitation
Μια πρόσκληση για το ΣΚ 💌

Αυτό το μικρό project φτιάχτηκε σαν ένας πιο ιδιαίτερος τρόπος για να ζητήσω από κάποιον άνθρωπο που με νοιάζει να βγούμε ραντεβού.

Δεν είναι κάτι μεγάλο. Είναι απλά μια μικρή διαδραστική σελίδα, φτιαγμένη με λίγη φαντασία, λίγο θάρρος και πολλή καλή πρόθεση.

Τι περιλαμβάνει

* Επιλογή ημέρας: Σάββατο ή Κυριακή
* Επιλογές για φαγητό, ποτό, γλυκό ή βόλτα
* Μια μικρή μυστική επιλογή
* Ένα κουμπί “Χμμ…” που δεν πιάνεται εύκολα
* Έτοιμο μήνυμα SMS όταν πατηθεί το “Ναι”

Τεχνολογίες

* HTML
* CSS
* JavaScript

Σημείωση

Η σελίδα φτιάχτηκε για ένα συγκεκριμένο άτομο.

Γιατί κάποιες φορές ένα απλό “πάμε για καφέ;” δεν είναι αρκετό.
